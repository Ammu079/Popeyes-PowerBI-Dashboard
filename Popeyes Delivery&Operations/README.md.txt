# Popeyes Delivery & Operations Dashboard (Power BI)

## 📊 Project Overview
This project showcases a Power BI dashboard created to analyze weekly delivery and operational performance for Popeyes.

The dashboard focuses on comparing delivery platforms, tracking sales performance against projections, and monitoring key operational KPIs.

Due to file size and sharing constraints, the Power BI (.pbix) file is not included. Instead, dashboard screenshots and the source data files are shared for reference.

---

## 📁 Files Included
- Dashboard Screenshot (PNG/JPG)
- Source Data Files (Excel)
- Project Documentation

---

## 📈 Dashboard Highlights
- Total Delivery Sales overview
- Platform-wise sales comparison (Deliveroo, Uber Eats, Just Eat)
- Projected vs Actual sales trend
- Customer ratings, refund %, and online time analysis
- Operational KPIs: ATV, Service Time, Large Meals

---

## 🔍 Key Insights
- Deliveroo and Uber Eats are the top-performing delivery platforms.
- Actual sales exceeded projected sales on multiple days.
- Higher service times are associated with increased refund percentages.
- Customer ratings remain consistent across platforms.
